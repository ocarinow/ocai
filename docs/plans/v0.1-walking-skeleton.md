# v0.1 — Walking skeleton *(internal milestone)*

**Goal:** prove the ports / adapters / middleware / canonical-types architecture
against ONE real provider, end to end, before multiplying it. Validates that the
table stakes are genuinely solid.

**Provider:** OpenAI only.

**Done when:** a 5-line chat call works sync *and* streaming against recorded
fixtures; errors normalize; retry middleware works; usage/cost reported;
everything typed.

**Not in scope:** conversion graph as a *feature*, second provider, RAG,
capabilities.

**Parallelism:** 1.1 first. Then 1.2 / 1.4 / 1.5 / 1.6 in parallel; 1.3 after 1.2.

> Read the root [CLAUDE.md](../CLAUDE.md) rules first. One WU per PR. Verify with
> `uv run ruff check && uv run pytest` and report results before finishing.
