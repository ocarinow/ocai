July 2026 re-architecture. They describe an API that no longer exists
(`core/types.py`, `SchemaVersion`, Engine/registry-era modules) and are kept
verbatim as history — do **not** pick WUs from them.

The live roadmap is [`docs/plans/README.md`](../README.md); the structural
contract it implements is [`docs/architecture.md`](../../architecture.md).
