# v1.0 — Promise-keeping & hardening

**Goal:** make the stability promise real and the project trustworthy and
professional.

**Done when:** stability is documented and guaranteed; the monitoring pillar
ships; the full middleware set is present; docs onboard a new user in ~5 minutes;
installs are clean across all extras; perf is acceptable.

> Read the root [CLAUDE.md](https://github.com/ocarinow/ocai/blob/main/CLAUDE.md) rules first. One WU per PR.

---

## WU 5.1 — Public-API stability commitment  ·  depends on: v0.4

- [ ] Semver + deprecation policy docs; the version-resilience promise written as
      a guarantee.
- [ ] Audit that every public symbol in `ocai.core` is intentional and
      additive-only going forward.

**Done:** a published stability/deprecation policy exists; the public API is
audited and documented as the v1 surface.

---

## WU 5.2 — `Tracer` port + observability adapters  ·  depends on: v0.3 middleware

- [ ] OpenTelemetry adapter (optionally Langfuse), wired as middleware. Closes the
      "monitoring" pillar.

**Done:** chat calls emit spans/traces through the `Tracer` port via middleware
against at least one real backend; documented.

---

## WU 5.3 — Remaining standard middlewares  ·  depends on: v0.2 middleware

- [ ] Caching + rate-limiting middleware, composing with the existing
      retry/fallback/tracing stack.

**Done:** cache and rate-limit middleware work and compose; tests cover hit/miss
and limit behavior.

---

## WU 5.4 — Comprehensive conformance + property tests  ·  depends on: v0.4

- [ ] Round-trip idempotence on surviving fields.
- [ ] Reachability invariant: every node pair is reachable while the backbone is
      intact.

**Done:** property tests assert round-trip idempotence and graph reachability
across the registered node set; green in CI for all languages.

---

## WU 5.5 — Packaging polish  ·  depends on: v0.3

- [ ] All extras wired (`ocai[all]`, per-provider); entry-point discovery solid;
      friendly missing-component errors everywhere; install matrix tested.

**Done:** every documented install path resolves correctly; a missing component
yields the friendly `pip install ocai[...]` hint; install matrix passes in CI.

---

## WU 5.6 — Docs  ·  depends on: most of v1

- [ ] 5-line quickstart; migration guide from the OpenAI SDK / LiteLLM; the
      escape-hatch guarantee; a per-provider capability matrix; runnable examples.

**Done:** a new user can go from zero to a working call in ~5 minutes following
the docs; examples run as written.

---

## WU 5.7 — Perf pass  ·  depends on: v0.2 graph

- [ ] Precompute all-pairs at registration so runtime conversion is an O(1) plan
      lookup; benchmark streaming overhead.

**Current state:** the graph memoizes plans lazily on first use
(graph.py (`../python/packages/ocai-core/src/ocai/core/graph.py`, historical path) has a
`# TODO: optional eager all-pairs warmup`). This WU implements that warmup +
benchmarks.

**Done:** all-pairs plans are precomputed at registration; runtime conversion is
an O(1) lookup; streaming overhead is benchmarked and documented as acceptable.
