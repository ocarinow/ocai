# v0.2 — The wedge, made visible *(first public release)*

**Goal:** demonstrate the differentiator — convert a request between providers
with an **honest fidelity report**, plus on-error fallback. This is the
screenshot moment.

**Provider:** add Anthropic.

**Done when:** you can switch OpenAI→Anthropic and get back a printed report of
exactly what didn't translate; a fallback chain survives a simulated 529; golden
fixtures per codec edge are green in CI. The README's first line states the
**version-resilience + honest-conversion** promise.

**Not in scope:** capability-based predictive routing, embeddings, polyglot.

**Parallelism:** 2.1 parallel throughout. Core path is 2.2 → 2.3 → (2.4, 2.5,
2.6 in parallel).

> Read the root [CLAUDE.md](https://github.com/ocarinow/ocai/blob/main/CLAUDE.md) rules first. From v0.2 the public
> `ocai.core` API is **semver-stable: additive changes only.**

## WU 2.2 — Conversion graph  ·  depends on: 1.1

- [ ] Registry, Dijkstra path-finding, path caching, canonical backbone node,
      `Report` accumulation along the path.

**Current state:** **largely implemented** in
graph.py (`../python/packages/ocai-core/src/ocai/core/graph.py`, historical path) (loss-weighted
Dijkstra, `HOP_PENALTY`, plan cache, backbone, `Report`). This WU is mostly
*verify + harden*: confirm determinism, cache invalidation on `register`, and the
≤2-hop backbone guarantee with multiple nodes registered.

**Done:** graph is covered by tests for multi-node routing (not just the trivial
direct-edge case), tie-breaking is deterministic, and the cache invalidates
correctly when edges are added.

## WU 2.3 — Codecs: OpenAI↔canonical + Anthropic↔canonical  ·  depends on: 2.2

- [ ] OpenAI↔canonical and Anthropic↔canonical (decode + encode), each with
      golden fixtures in `spec/fixtures/`. Any→any via the pivot now works.

**Current state:** OpenAI↔canonical codec + edges exist
(adapter.py (`../python/packages/ocai-openai/src/ocai/openai/adapter.py`, historical path)) with
one golden fixture. Add the Anthropic codec + its edges + fixtures, and broaden
OpenAI fixture coverage (tool calls, system prompt, multi-turn).

**Done:** both providers decode↔encode against golden fixtures; an
OpenAI→Anthropic conversion routes through canonical and produces a valid
Anthropic payload + a `Report`; all fixtures green in CI.
