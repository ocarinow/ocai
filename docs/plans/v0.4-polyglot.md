# v0.4 — Polyglot parity *(the claim no competitor can match)*

**Goal:** a TypeScript implementation with **identical behavior, proven by the
same conformance fixtures.** Built on the spec-centered monorepo, this is
uniquely ocai's.

**Done when:** the TS library passes the identical golden fixtures as Python, CI
enforces parity, and the `@ocai/*` npm workspace publishes. Go optional.

**Parallelism:** 4.1 first (gates everything). 4.2 → (4.3, 4.4). 4.5 can wait.

> Read the root [CLAUDE.md](../CLAUDE.md) rules first. `spec/` is the contract;
> both languages consume the same fixtures. Any divergence fails CI.

---

## WU 4.1 — Freeze the contract  ·  depends on: v0.3  ·  GATES 4.2–4.5

- [ ] Lock IR JSON Schema + fixture format; expand fixture coverage (tools,
      structured output, streaming chunks, errors, both wire versions from 3.5).
- [ ] Ensure Python passes 100% of the frozen set.

**Done:** the schema + fixture format are versioned and stable; Python is green
on the full expanded set; the contract is documented as the parity baseline.

## WU 4.3 — TS adapters: OpenAI + Anthropic  ·  depends on: 4.2

      `raw`), backed by recorded HTTP fixtures.

**Done:** TS OpenAI + Anthropic adapters pass the same behavioral fixtures as

## WU 4.4 — Shared conformance runner  ·  depends on: 4.2

- [ ] Python and TS both execute `spec/fixtures/` in CI; **any divergence fails
      the build.** Wire into the existing path-filtered workflow (the `typescript`
      job is currently a stub).

**Done:** CI runs both languages against `spec/fixtures/` and fails on any
mismatch; the drift alarm spans languages.
