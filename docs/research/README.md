# Integration research

- [Provider wire research](providers/README.md): dated vendor investigations.
- [Capability research](capabilities/README.md): opportunity and integration analysis.

A vendor capability, a proposed mapping or a registered node is not proof that
ocai implements that operation. Consult [supported features](../user/provider-feature-matrix.md)
and the owning tests. Preserve source dates; recheck live vendor facts when
implementing an integration. Research priorities are historical inputs; the
[current roadmap](../plans/README.md) owns delivery order.
