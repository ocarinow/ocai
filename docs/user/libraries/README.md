# Libraries

Python is the implemented language library. The distributions share the `ocai`
namespace; provider codecs, credentials and hosts can be installed separately.

- [Python installation and first call](python/README.md)
- [Provider and host configuration](../guides/providers.md)
- [Supported features](../provider-feature-matrix.md)
- [Package API reference](../reference/README.md)

The TypeScript and Go library ports are placeholders. The platform's private
TypeScript management client is a different surface; it is not a TypeScript port
of the Python AI library.
